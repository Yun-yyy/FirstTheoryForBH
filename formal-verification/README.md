## 如何理解验证结果

`proof fn` 的参数是任意的数学量。Verus 必须证明：对所有满足 `requires` 的参数，`ensures` 均成立。参数类型 `int` 是无界数学整数，不是会溢出的 Rust `i64`。空证明体并不是跳过证明；对于可自动处理的目标，SMT 求解器直接承担证明义务。错误命题即使采用同样的空证明体，也应被拒绝。

本项目没有把 DFT 结果写进前提，也没有执行 DFT。数学模型和实验事实分开记录。

## 一 从二轨道哈密顿量出发

取两个正交轨道，忽略此子空间之外的自由度，令有效哈密顿量为

```
H = [ a  -t ]
    [ -t  b ]
psi = (x + i y, u + i v)
N = x² + y² + u² + v² > 0
Q = a(x²+y²) + b(u²+v²) - 2t(xu+yv)
E(psi) = Q/N
```

`a,b` 是轨道在位能，`t` 是轨道耦合，`N` 是未归一化波函数的范数平方。允许未归一化振幅可以避免将平方根或浮点数混入证明。

若给定候选下界 `L`，令 `A=a-L`，则可以逐项展开得到：

```
A(Q-LN)
  = (Ax-tu)² + (Ay-tv)²
    + [A(b-L)-t²](u²+v²).
```

只要 `A>0` 且 `A(b-L)-t²>=0`，右侧非负，所以 `Q>=LN`，进而在 `N>0` 时有 `E(psi)>=L`。代码验证的是交叉相乘后的精确关系，不依赖浮点容差。这里验证了有限矩阵模型中的能量下界证书。

对称特例 `a=b=e,t>0` 中，取 `L=e-t`，证书行列式为零；`(1,1)` 恰好达到下界，能量为 `e-t`；`(1,-1)` 的能量为 `e+t`。由“所有态不低于此值”和“存在态达到此值”共同确定模型基态，不能只检查某一个向量就宣称找到基态。

`int` 可编码有理参数：能量使用一个正公分母，振幅使用另一个正公分母；乘去正分母后得到代码中的式子。因此该证明适用于此编码下的任意有理输入。尚未形式化连续延拓到任意实参数，也未形式化无限维希尔伯特空间。

### 对应 Word 的 P047

在固定的对称轨道模型中，成键和反键占据数分别为 `nb,na`，相对于两个无耦合等能轨道的电子能量稳定化量为

```
S = (nb-na)t.
```

代码还证明了桥接关系 `nb(e-t)+na(e+t)=(nb+na)e-S`，将稳定化量连接到前面得到的轨道能级，而不是只为 S 另下一个无关定义。

移走一个成键电子：`S'=(nb-1-na)t=S-t`。
加入一个反键电子：`S''=(nb-na-1)t=S-t`。
在 `t>0` 时，两者都降低这一稳定化量，尽管总电子数改变方向相反。这解释了原文中“Li 空位导致成键区失电子”和“过渡金属相关电子进入反键态”为什么在模型层面不矛盾。

真实 B–H 是异核、多轨道、多电子体系。此对称模型是解释占据效应的可证明特例，不能定量替代 B–H 的 DFT。不同电子数的总自由能比较还需要电子库化学势；局部稳定化量下降也不自动等于放氢活化自由能下降。原文中的这两条物理映射依然需要电子结构与路径计算支持。

## 二 反应能与势垒必须分开

对给定反应坐标和共同过渡态，记端点能量为 `a,b`，过渡态为 `ts`：

```
forward = ts-a
reverse = ts-b
reaction = b-a
forward-reverse = reaction
```

若只令 `ts` 降低 `d>0`，保持端点不变，则两个势垒均降低 `d`，端点差不变。这对应 Word 对“动力学加快不独立证明热力学去稳定化”的区分。

若端点也改变，结论不再成立。精确反例是：

```
原模型：a=0, b=0,  ts=10 → 正向10，逆向10
新模型：a=0, b=-5, ts=8  → 正向 8，逆向13
```

正向势垒降低，而逆向势垒升高。代码会同时验证这个反例，并尝试证明错误的普遍命题，要求后者被拒绝。它说明反应产物被深度稳定化时，“更容易放氢”与“更难回充”在模型内可以同时发生。

这些关系可以解释为同一参考和同一条件下的能量或自由能。未形式化过渡态理论、指数速率函数、氢逸度、完整反应网络或真实催化剂表面。

## 三 容量分母和可逆性不能互相偷换

若只由活性组分提供氢，且 `0<=h<=active<=total`，则有 `h/total<=active/total`；添加惰性质量 `host>0`，对于同一个氢量 `h>=0`，有 `h/(active+host)<=h/active`，其中 `active>0`。代码用交叉相乘验证关系，并公开分母正性。

这不证明添加载体必然使实验容量下降，因为载体也可能使实际释放量 `h` 上升；命题明确限定为相同 `h`。这正是原文强调质量基准和测试条件的原因。

对于化学状态，取抽象观测 `Q(x,y)=4x+y`，其中 `x,y` 表示两类储氢组分的相量。`(1,0)` 和 `(0,4)` 的容量均为4，但组成不同。代码构造这个反例，否定“一个容量数值普遍决定相组成”的推断。这里没有声称这两组相量满足同一个真实样品的 Mg/B 收支。

另一个独立证明检查以下示意反应的元素收支：

```
Mg(BH4)2 → MgH2 + 2B + 3H2
MgH2     → Mg   + H2
```

这与 Word 对 P064 的讨论相接：变成 MgH2 参与后续循环，在化学上具有守恒的可能路径；保持储氢功能不必意味着恢复原始 Mg(BH4)2。但仅有守恒不证明实际反应发生，具体样品仍需要原位谱学、定量相分析和气体测量。

## 可信基础与不能越过的边界

Verus 使用 Rust 前端与 SMT 求解器进行验证。可信基础包含 Verus 编码、Z3、所用标准验证库及工具链。本项目没有生成供 Lean 独立内核重放的证明证书，也没有形式化验证验证器本身。

交付源文件将审计 `assume`、`admit`、`external_body` 和跳过验证的属性。未发现这些逃逸机制，只说明任务自身没有显式引入它们；不等于所有依赖没有公理或可信实现。

错误命题的“验证失败”本身不自动构成数学反证，因为也可能是求解器能力不足。本项目同时提供具体反例，使错误结论可以独立检查。
